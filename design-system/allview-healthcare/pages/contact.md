# Page Override: Contact (`/contact`)

**Overrides:** Brand navy `#002f87`, purple `#7d1690`, cyan `#60cbe8`, Vhi `#c40d3c`. Ignore teal MASTER tokens.

## Intent

Make the user *want* to engage. First choose who they are, then one obvious action: call or request a call back.

## Pattern

Lead magnet + form, healthcare-flavoured: Hero (benefit) → Path picker → One phone CTA + 3-field form → HQ map → Hours.

- Form fields ≤ 3 (name, phone, optional note).
- Disable submit + “Sending…” while pending.
- “Open now” from Ireland weekday 9–5, plus always-visible hours (colour is not the only cue).

## Interaction

- Path chips change number, copy and submit colour (Vhi red).
- Call buttons ≥44px. Map lazy-loaded.
- Skip: tel: links always visible.

## Anti-patterns

- Long generic “contact us” form.
- Phone numbers as plain text.
- Frozen submit with no loading state.

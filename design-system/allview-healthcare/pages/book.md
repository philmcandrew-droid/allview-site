# Page Override: Book (`/book`)

**Overrides:** Brand navy `#002f87`, purple `#7d1690`, cyan `#60cbe8`, Vhi `#c40d3c`. Ignore teal MASTER tokens.

## Intent

Conversion-optimised booking. Choose a pathway visually, then a short form. Transparent wait and price beside the fields.

## Pattern

Trust & Authority + Conversion: Hero → Path cards (single CTA each) → Form + proof column → Success.

- Form: name, phone, email. Optional referrer only on HSE.
- Loading then success. Labels on every field.
- Vhi CTA is Vhi red; others navy.

## Anti-patterns

- Radio list with no visual difference between paths.
- Text-only page with no trust signals.
- Placeholder-only inputs.
